# Benesse TAB-A04-BR3（a04br3）

a04br3 是 Benesse TAB-A04-BR3，一款搭载 MediaTek MT8167（四核 Cortex-A35、GIC-400、2 GiB DRAM、eMMC）的 10 英寸学习平板。下面的移植是独立的社区项目，UniXNU 组织不维护它。它沿用 UniXNU 的启动链：由原厂 LK 引导加载程序启动的 Mu-Silicium UEFI 移植、DarwinBoot、与 sheng 相同的 iPadOS 17.7.11（21H461）kernelcache 和原生 4 KiB XNU，以及 eMMC 上的原始 OS 卷。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-a04br3](https://github.com/mouseos/UniXNU-a04br3) | [mouseos](https://github.com/mouseos) | 内核、payload、userdata 和启动镜像已在 CI 构建；尚未在真机运行 |
| [uefi-a04br3](https://github.com/mouseos/uefi-a04br3) | [mouseos](https://github.com/mouseos) | Mu-Silicium UEFI 移植（MT8167Pkg、Benesse/a04br3Pkg）；可用 `unixnu build firmware` 构建 |

## 状态

| 阶段 | 状态 |
| --- | --- |
| 启动 | 原厂 LK（已解锁）加载带 MediaTek `KERNEL`/`ROOTFS` 头（`mtk_header`）的 Android 启动镜像 v0；UEFI 固件卷和 payload 卷位于 `boot` 分区 |
| 固件 | Mu-Silicium 移植已构建；GOP 使用 LK 帧缓冲，eMMC Block I/O，启动 ramdisk 卷 |
| CPU | ArmCpu 的 GICv2（GIC-400）路径，`ARMCPU_GICV2`；四核，4 KiB 页 |
| 控制台 | 16550 UART0，921600 波特（`XNU_NS16550_UART`） |
| 存储 | NativeMsdc（`XNU_NATIVE_MSDC`）以只读方式发布 userdata 分区中的 OS 窗口；Data 来自 RAM 盘 |
| 无人值守测试 | 板级测试循环让每次复位都回到 LK fastboot，首次安装后无需 mtkclient 即可写入并启动镜像 |
| 真机运行 | 尚未进行；同一维护者此前的非 UniXNU XNU 移植已在该平板上到达 Setup |
| GPU、音频、Wi-Fi、触控 | 不可用 |

## 构建

内核、userdata 和 payload 步骤在 UniXNU 的 macOS 工作流中运行，参数为 `device_repository = mouseos/UniXNU-a04br3`、`defconfig = a04br3_defconfig` 以及设备仓库的 `pre_build` 脚本。它所需的基础改动（16550 控制台、板级钩子、MSDC 存储、MediaTek 镜像头、ArmCpu GICv2）都在默认关闭的开关之后，并以拉取请求提交；合并之前请使用分叉 [mouseos/UniXNU](https://github.com/mouseos/UniXNU) 构建。固件和启动镜像用常规命令构建：

```sh
./unixnu defconfig a04br3_defconfig -D ../UniXNU-a04br3
./unixnu fetch
./unixnu build firmware --uefi ../uefi-a04br3
./unixnu bootimg --uefi ../uefi-a04br3 --dtb ../uefi-a04br3/Resources/DTBs/a04br3.dtb
```

设备仓库的 `scripts/make-a04br3-flash.py` 生成首次安装用的 mtkclient 脚本（boot、userdata，以及去掉未使用 Android 分区的 GPT；保留 `logo`）。之后的镜像通过 LK fastboot 用 `scripts/run-a04br3-unattended.sh` 写入。
