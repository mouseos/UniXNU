# Benesse TAB-A04-BR3 (a04br3)

a04br3 is the Benesse TAB-A04-BR3, a 10-inch learning tablet with the MediaTek MT8167 SoC (four Cortex-A35 cores, GIC-400, 2 GiB DRAM, eMMC). The port below is an independent community project. The UniXNU organization does not maintain it. It follows the UniXNU stack: a Mu-Silicium UEFI port started by the stock LK bootloader, DarwinBoot, the iPadOS 17.7.11 (21H461) kernelcache of sheng with the native 4 KiB XNU, and the original OS volume on the eMMC.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-a04br3](https://github.com/mouseos/UniXNU-a04br3) | [mouseos](https://github.com/mouseos) | Kernel, payload, userdata and boot image built in CI; no hardware run yet |
| [uefi-a04br3](https://github.com/mouseos/uefi-a04br3) | [mouseos](https://github.com/mouseos) | Mu-Silicium UEFI port (MT8167Pkg, Benesse/a04br3Pkg); builds with `unixnu build firmware` |

## State

| Stage | State |
| --- | --- |
| Boot | Stock LK (bootloader unlocked) loads an Android boot image v0 with MediaTek `KERNEL`/`ROOTFS` headers (`mtk_header`); the UEFI firmware volume and the payload volume are in the `boot` partition |
| Firmware | Mu-Silicium port built; GOP from the LK framebuffer, eMMC Block I/O, boot ramdisk volume |
| CPU | ArmCpu with the GICv2 (GIC-400) path, `ARMCPU_GICV2`; four cores, 4 KiB pages |
| Console | 16550 UART0 at 921600 baud (`XNU_NS16550_UART`) |
| Storage | NativeMsdc (`XNU_NATIVE_MSDC`) publishes the OS windows of the userdata partition read-only; Data from a RAM disk |
| Unattended testing | the board's test cycle returns every reset to LK fastboot, so images are written and booted without mtkclient after the first installation |
| Hardware runs | not yet; earlier non-UniXNU XNU ports by the same maintainer reached Setup on this tablet |
| GPU, audio, Wi-Fi, touch | not available |

## Build

The kernel, userdata and payload steps run in the macOS workflow of UniXNU with `device_repository = mouseos/UniXNU-a04br3`, `defconfig = a04br3_defconfig` and the `pre_build` script of the device repository. The base changes it needs (16550 console, board hook, MSDC storage, MediaTek image headers, ArmCpu GICv2) are behind default-off flags and offered as pull requests; until they are merged the port builds with the fork [mouseos/UniXNU](https://github.com/mouseos/UniXNU). The firmware and the boot image are built with the regular commands:

```sh
./unixnu defconfig a04br3_defconfig -D ../UniXNU-a04br3
./unixnu fetch
./unixnu build firmware --uefi ../uefi-a04br3
./unixnu bootimg --uefi ../uefi-a04br3 --dtb ../uefi-a04br3/Resources/DTBs/a04br3.dtb
```

`scripts/make-a04br3-flash.py` of the device repository writes an mtkclient script for the first installation (boot, userdata, a GPT without the unused Android partitions; `logo` stays). Later images go through LK fastboot with `scripts/run-a04br3-unattended.sh`.
